# سجل درجات الطلاب: تطبيق الويب والأندرويد

مجلد `www/` هو التطبيق كاملًا ويعمل دون إنترنت (المكتبات والخطوط محلية). منه نصنع:
1. **نسخة ويب** للحاسوب والهاتف (تُثبَّت كتطبيق PWA).
2. **ملف APK** لأندرويد عبر Capacitor.

المزامنة بين الأجهزة تتم برمز دخول، وتُحفظ البيانات مشفّرة في قاعدة Supabase المرتبطة بحسابك.

## أولًا: الحصول على ملف APK (أسهل طريقة، دون تثبيت أي برنامج)
1. أنشئ حسابًا مجانيًا في github.com، ثم مستودعًا جديدًا (Private).
2. ارفع محتويات هذا المجلد كلها إلى المستودع (زر Add file ← Upload files، واسحب الملفات والمجلدات، بما فيها المجلد المخفي `.github`).
3. افتح تبويب **Actions**، اختر **Build Android APK**، ثم **Run workflow**.
4. بعد نحو 5 دقائق افتح التشغيل المكتمل، ونزّل الملف `gradebook-apk` من قسم Artifacts، وفكّ ضغطه تجد `app-debug.apk`.
5. انقل الملف إلى الهاتف وافتحه، وفعّل «التثبيت من مصادر غير معروفة» إن طُلب منك.

## ثانيًا: البناء على حاسوبك (اختياري)
المتطلبات: Node 22، وJDK 21، وAndroid Studio (أو Android SDK).
```
npm install
npm run build:www     # يعيد بناء www من src/index.source.html
npx cap sync android
cd android && ./gradlew assembleDebug
```
الناتج: `android/app/build/outputs/apk/debug/app-debug.apk`

## ثالثًا: نسخة الويب
ارفع مجلد `www/` كما هو إلى أي استضافة ثابتة (Netlify Drop أو GitHub Pages)، ثم افتح الرابط في المتصفح واختر «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».

## تحديث التطبيق لاحقًا
عدّل `src/index.source.html`، ثم شغّل `npm run build:www` و`npx cap sync android`، وابنِ APK جديدًا. تُحدَّث نسخة الويب تلقائيًا عند فتحها وفيها إنترنت.

## ملاحظات
- ملف APK هنا للتجربة والتثبيت المباشر (debug). النشر في Google Play يحتاج توقيعًا خاصًا وحساب مطوّر.
- رمز الدخول هو مفتاح بياناتك: من يملكه يصل لها. لا تشاركه علنًا.
